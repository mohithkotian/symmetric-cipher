Introduction to Symmetric Cryptography

Symmetric cryptography is a method of encryption where the same secret key is used to encrypt plaintext and decrypt ciphertext. Because the key must be shared securely between both communicating parties prior to transmission, understanding the foundational mechanics of substitution and modulo-26 letter shifting is crucial.

Theoretical Background

Numeric-Key Modulo-26 Caesar Cipher

1

What is Symmetric Cryptography?

Symmetric cryptography uses the same secret key for both encryption and decryption. The sender and receiver must share that key before communicating.

2

Symmetric Cipher Model

Plaintext↓Encryption Algorithm + Secret Key↓Ciphertext↓Decryption Algorithm + Same Secret Key↓Plaintext
3

What is a Cipher?

Plaintext is the original readable message.

Encryption transforms plaintext into ciphertext, an altered message.

Decryption reverses the transformation and recovers the plaintext.

4

Alphabet Mapping

Each English letter receives a zero-based numeric value.

A = 0    B = 1    C = 2    ...
W = 22   X = 23   Y = 24   Z = 25
5

Modulo-26 Encryption

For each letter, add the numeric key to its alphabet value and wrap the result within 0–25.

C = (P + K) mod 26
6

Modulo-26 Decryption

For decryption, subtract the same key. Adding 26 before the modulo keeps the result non-negative.

P = (C − K + 26) mod 26
7

Key Greater Than 26

K = 30
30 % 26 = 4
effective shift = 4
H = 7
(7 + 30) % 26 = 11
11 = L

The original key remains visible and is not hidden when calculating its effective shift.

8

Alphabet Wrapping

When a shift passes Z, modulo arithmetic wraps back to A.

Y + 4 = C
(24 + 4) % 26 = 2
9

Security Limitations

A classical Caesar cipher is intended for education. Its small effective keyspace makes it weak against brute-force attempts and other basic cryptanalysis techniques. It is not suitable for real-world secure communication.

Frequently Asked Questions

Modulo 26 keeps every shifted letter inside the A–Z alphabet. For example, key 30 has effective shift 4 because 30 % 26 = 4.

The simulator calculates an effective shift with key % 26, so keys greater than 26 work without hiding the original key.

A Caesar cipher is simple and useful for learning substitution and modulo arithmetic, but it is not suitable for protecting real-world secrets.

Decryption subtracts the same effective shift, wrapping around the alphabet to recover the original letters exactly.

Only English alphabet letters are shifted. Spaces, punctuation, and numbers pass through unchanged while uppercase and lowercase are preserved.
